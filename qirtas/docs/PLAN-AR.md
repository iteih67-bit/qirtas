# الخطة التنفيذية — منصة «قِرطاس» للمكتبة الرقمية العربية

> خطة عربية مكتوبة قبل التنفيذ، يتبعها تنفيذ فعلي دون توقف حتى إكمال الموقع أو نفاد الرصيد.
> تفاصيل التنفيذ التقنية الداخلية (قائمة الروابط، طريقة الجمع، إعدادات الخادم) **لا تُذكر في الموقع العام**.

---

## 1) هدف النسخة الأولى

موقع مكتبة رقمية عربي أولًا (RTL) + تطبيق قراءة يعمل على الجوال والتابلت والحاسوب والقارئ الإلكتروني،
يعرض كتبًا حرة قانونيًا بنص كامل، ويمنح **كل كتاب** ملاحظة مصدر وترخيص **ونموذج طلب إزالة** لأصحاب الحقوق،
مع **لوحة تحكم** للإدارة وقاعدة بيانات حقيقية، وربط بمستودع GitHub ونشر HTTPS مع نسخ احتياطي وتراجع.

## 2) صفحات الموقع (المخرج العام)

| الصفحة | الوظيفة |
|---|---|
| `/` الرئيسية | أرقام المكتبة، أحدث الإضافات، دخول سريع للبحث |
| `/library/` المكتبة | بحث عربي متسامح (تشكيل/همزات/تاء مربوطة) + فلاتر: اللغة، التصنيف، المصدر، الحقبة الزمنية + ترقيم صفحات + رابط قابل للمشاركة |
| `/book/<id>/` صفحة الكتاب | غلاف، بيانات كاملة (عنوان/مؤلف/مترجم/ناشر/سنة/تصنيف/لغة)، فهرس الفصول، **ملاحظة المصدر والترخيص**، زر قراءة + زر تنزيل (EPUB/PDF عند توفره)، وزر «طلب إزالة» |
| `/read/<id>/` القارئ | ترقيم أفقي، تحكم بحجم الخط، وضع ليلي/نهاري/سيبيا، حفظ موضع القراءة، فهرس، تنقّل باللمس ولوحة المفاتيح، **متوافق مع كل المقاسات** |
| `/category/<c>/` التصنيفات | تصفّح حسب التصنيف |
| `/author/<slug>/` المؤلفون | تصفّح حسب المؤلف |
| `/era/<e>/` الحقب | تصفّح حسب الحقبة الزمنية |
| `/about/` · `/contact/` · `/privacy/` · `/rights/` | التعريف، التواصل، الخصوصية، حقوق النشر وطلب الإزالة |
| `/admin/` | لوحة تحكم محمية: الكتب، الطلبات، عمليات الجذب، سجل التدقيق |

## 3) لوحة التحكم (محمية بكلمة مرور)

- **الكتب:** عرض/بحث/تعديل/إخفاء/إزالة/استرجاع، تعديل الحقول الوصفية.
- **الطلبات:** قائمة طلبات الإزالة بحالات (`pending → reviewing → removed / kept`) + قرار مكتوب + طابع زمني.
- **الجذب:** سجل كل تشغيل (المصدر، وقت البدء، أُضيف، تُخطّي، فشل، المدة) + الأخطاء.
- **سجل التدقيق:** كل إجراء إداري بالوقت والفاعل ونوع الإجراء والهدف.
- منع الوصول بلا تسجيل دخول (يُختبر فعليًا).

## 4) قاعدة البيانات (SQLite مدمجة في Node — بلا خدمات مدفوعة)

| الجدول | أهم الحقول |
|---|---|
| `books` | id, slug, title, title_en, author, translator, publisher, year, era, category, language, source_key, source_url, license_type, license_label, cover, file_path, file_format, words, chapters, hidden, created_at, updated_at |
| `book_texts` | book_id, chapters_json (أو مسار الملف) |
| `takedown_requests` | id, book_id, requester_name, requester_role, contact_email, claim_type, official_url, message, status, decision_note, created_at, reviewed_at, reviewer |
| `import_runs` | id, source_key, started_at, finished_at, added, skipped, failed, notes, log_path |
| `audit_log` | id, actor, action, target_type, target_id, details, created_at |

- تطبيع النص العربي: إزالة التشكيل، توحيد (أ/إ/آ→ا)، (ى→ي)، (ة→ه)، وتخزين `search_key` جاهزًا للبحث.
- إزالة التكرارات: بالمُعرّف ثم بالمفتاح المطبَّع (عنوان+مؤلف).
- الكتالوج العام (`catalog.json`) يصبح **تصديرًا** من قاعدة البيانات، وليس المصدر الأساسي.

## 5) المصادر والتدقيق الحقوقي

سجل مفصّل لكل مصدر: الرابط، الترخيص، شرط `robots.txt`/شروط الاستخدام، ما هو مسموح سحبه، وحكمه (مقبول / ميتاداتا وربط فقط / مرفوض).
يُرفض أي مصدر: (أ) يمنع الجمع الآلي، (ب) محتواه محمي بحقوق ناشر دون إذن، (ج) خلف DRM أو دفع أو تسجيل دخول.

## 6) القارئ ومخاطبة الأجهزة

- هاتف (‏320–480px): أعمدة بعرض الشاشة، مناطق لمس للتقليب، خط أساسي 1.05rem.
- تابلت (‏600–900px): هامش أوسع وعرض سطر محسّن.
- حاسوب (‏1024–1440px+): عمودان، عرض سطر ~66 محرفًا (مبدأ Reading-First).
- قارئ إلكتروني/شبكات بطيئة: بلا خطوط خارجية ثقيلة، تحميل النص عند الطلب، عمل دون إنترنت بعد أول تحميل.
- إعدادات محفوظة لكل جهاز: حجم الخط، الثيم، الموضع، المفضلة.

## 7) الجدول الزمني

| المرحلة | المخرج | الحالة |
|---|---|---|
| 1 | الخطة العربية + سجل المصادر والترخيص | هذه الرسالة |
| 2 | قاعدة البيانات + ترحيل الكتب العربية وتطبيعها | بعد الخطة مباشرة |
| 3 | لوحة التحكم + طلبات الإزالة + سجل التدقيق | المرحلة التالية |
| 4 | تحسين التصميم والقارئ لكل الأجهزة | ثم |
| 5 | الفحص الشامل (مقاسات، طلبات، صلاحيات، مسارات خطأ) | ثم |
| 6 | الربط بمستودع GitHub (يحتاج حضورك عند كلمة المرور/2FA) | بعد جاهزية الكود |
| 7 | النشر على HTTPS + نسخ احتياطي/استرجاع/تراجع | الأخير |
| 8 | دليل التسليم الكامل | مع كل مرحلة |

1. تسجيل الدخول إلى GitHub بحسابك `iteih67@gmail.com` — **أنت** من يكتب كلمة المرور ورمز التحقق.

3. أي إجراء حذف نهائي/غير قابل للتراجع على بيانات حقيقية.

## 9) المخاطر وضوابطها

| الخطر | الضابط |
|---|---|
| مصدر يحمي حقوقه | لا نستضيف نصه؛ نعرض بيانات ورابطًا فقط، ووسم «حقوق محفوظة» |
| طلب إزالة من صاحب حق | يُسجّل فورًا بحالة `pending` ويُراجع ويُنفّذ خلال أيام عمل قليلة |
| حجم النصوص الكبير | النصوص خارج صفحات الموقع (ملفات منفصلة) + تحميل عند الطلب + تخزين مضغوط عند النشر |
| جودة النصوص الآلية | فلترة آلية (تحويلات/فصول فارغة) + مراجعة عيّنات + زر إبلاغ في القارئ |
| تعطّل مصدر | تسجيل الفشل في سجل الجذب، واستمرار بقية الكتب |
