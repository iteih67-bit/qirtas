# خط محتوى قِرطاس — المصادر، الأساس القانوني، وأوامر التشغيل

> الهدف: بناء مكتبة كبيرة (>‏1000 كتاب) بالعربية والإنجليزية من مصادر **حرة قانونياً فقط**،
> بأدوات مجانية بالكامل (Node.js + واجهات عامة بلا مفاتيح).

## 1) جدول المصادر

| المصدر | اللغة | طريقة الوصول | الترخيص | الحكم |
|---|---|---|---|---|
| **Project Gutenberg** | إنجليزي (63,000+ عنوان) | `gutendex.com` للكتالوج + `gutenberg.org/cache/epub/<id>/pg<id>.txt` للنص | ملكية عامة (شعار Gutenberg علامة تجارية — نزيل الترويسة ونشير للمصدر) | ✅ نص كامل قابل لإعادة النشر |
| **ويكي مصدر العربية** | عربي (‏94,000 صفحة، منها مئات الكتب ذات الفصول) | MediaWiki API (`ar.wikisource.org/w/api.php`) | ملكية عامة أو رخص حرة (CC-BY/CC-BY-SA للمساهمات) | ✅ نص كامل مع الإشارة للمصدر |
| **ويكي مصدر الإنجليزية** | إنجليزي (مسرحيات، قصص، كلاسيكيات) | نفس الواجهة (`en.wikisource.org`) | ملكية عامة / CC | ✅ نص كامل مع الإشارة |
| **مؤسسة هنداوي** | عربي | لا واجهة عامة مستقرة (‏403 على الطلبات الآلية) | رخصة النُسخ الإلكترونية تقيّد إعادة النشر | ⚠️ ربط خارجي فقط — لا ننسخ ملفاتها |
| **Internet Archive** | متعدد | `advancedsearch.php` متاح | يختلف لكل عنصر (ملكية عامة أو إعارة مقيدة) | ⚠️ يصلح للميتاداتا/الربط؛ التوزيع يحتاج فحص كل عنصر |
| **Google Books API** | متعدد | API عام | ميتاداتا فقط | ⚠️ ميتاداتا/ربط |
| **LibriVox** | صوتي | واجهة الكتالوج | ملكية عامة | ✅ صوت (مرحلة لاحقة) |

**قاعدة ثابتة:** لا نُنزّل ولا نستضيف أي كتاب محمي بحقوق ناشر أو من موقع غير مرخّص.
كل كتاب في الكتالوج يحمل `sourceUrl` و`licenseLabel` ويظهران للمستخدم في صفحة الكتاب.

## 2) أوامر التشغيل

```bash
npm install                 # مرة واحدة (cheerio فقط للمعالجة)

# --- الجذب ---
npm run books:harvest                        # جوتنبرج: يبني قائمة المرشحين من top-1000 تحميل فعلي
npm run books:fetch -- --limit=250           # تنزيل + تنظيف + تقسيم فصول
npm run books:ws  -- --limit=110 --scan=260  # ويكي مصدر العربية (اكتشاف آلي للكتب ذات الفصول)
npm run books:ws-en -- --limit=40            # ويكي مصدر الإنجليزية

# --- الكتالوج الخارجي (ميتاداتا + روابط قراءة من المصدر، بلا استضافة) ---
npm run books:openlibrary -- --lang=ar --limit=5000
npm run books:openlibrary -- --lang=en --limit=8000

# --- الترخيص ---
npm run books:licenses                        # يقرأ صفحة كل كتاب ويكي مصدر ويستخرج قوالب الترخيص
npm run books:license-labels -- --drop-review # يثبّت العلامات ويعزل نسخ الناشرين الحديثة

# --- المعالجة والنشر ---
npm run books:clean      # إزالة التكرارات + ترتيب العناوين + حذف نصوص يتيمة
npm run books:clean-texts # إسقاط الفصول التنقلية/الفارغة وإعادة حساب الأرقام
npm run books:migrate    # ترقية المخطط (المصدر، الترخيص، رابط المصدر، لغة، تاريخ التحديث)
npm run books:index      # فهرس بحث خفيف books-data/index.json
npm run site:build       # توليد الموقع الكامل → site/dist
npm run site:serve       # معاينة على http://localhost:8081
npm run test:smoke       # فحص HTTP شامل
npm run test:ui          # فحص تفاعلي بمتصفح حقيقي (يحتاج خادمًا يعمل على 8081)
```

### خيارات مفيدة
| الخيار | الأثر |
|---|---|
| `--limit=N` | أقصى عدد كتب يُضاف في التشغيل |
| `--scan=N` | عدد دفعات مسح العناوين في ويكي مصدر (500 عنوان/دفعة، الافتراضي 240 ≈ 120 ألف عنوان) |
| `--minsub=N` | أقل عدد صفحات فرعية لاعتبار الصفحة «كتاباً» (الافتراضي 3) |
| `--maxch=N` | أقصى عدد فصول يُحفظ للكتاب (الافتراضي 18) |
| `--minwords=N` | أدنى حجم مقبول للكتاب (الافتراضي 3000 كلمة) |
| `--rescan` | تجاهل ذاكرة العناوين وإعادة المسح |

## 3) كيف يكتشف جامع ويكي مصدر الكتب؟

الكتب في ويكي مصدر ليست مصنّفة بوسم موحّد، لكنها **مبنية على صفحات فرعية**:
صفحة أصل `كتاب الأم` وتحتها `كتاب الأم/كتاب الصلاة`… لذلك:

1. مسح كل صفحات النطاق الرئيسي (بلا تحويلات) عبر `list=allpages`.
2. تجميع العناوين التي تحتوي `/` وحساب عدد الصفحات الفرعية لكل جذر.
3. اعتبار كل جذر له ≥ `--minsub` صفحة فرعية «كتاباً» (يستبعد القصائد المفردة والفهارس).
4. قراءة قالب الترويسة للجذر (`مؤلف` / `عنوان` / `سنة`) لاستخراج الميتاداتا.
5. عرض كل فصل عبر `action=parse` واستخراج الفقرات من `.mw-parser-output` بعد إزالة الجداول والترويسات.
6. رفض الكتب الرقيقة (< `--minwords`) وتسجيل السبب في `cache/ws-mass-report-<lang>.json`.

> **ملاحظة تحقق:** هذا الأسلوب جُرّب فعلياً بتاريخ 2026-09-21 على `ar.wikisource.org`
> (‏1441 عنواناً في 6 دفعات ⇒ 3 كتب مؤكدة) ثم على المسح الكامل.

## 4) بوابات الجودة

| البوابة | الفحص | مكان الدليل |
|---|---|---|
| ملكية/ترخيص | لا كتاب بلا `sourceUrl` + `licenseLabel` | `catalog.json` |
| حجم النص | ≥ 3000 كلمة و ≥ فصلين | تقرير الجذب |
| سلامة JSON | كل ملف نص يُقرأ ويُقسَّم بنجاح | تحذيرات `site:build` |
| اكتمال العرض | كل كتاب له صفحة + قارئ + ملف نص | `site/dist/book/*`, `read/*`, `books/*` |
| الاتجاه | نص عربي يُعرض RTL داخل القارئ | `read/<id>/` |

## 5) خطة النمو

- أسبوعياً: `books:harvest` + `books:fetch --limit=25` + `books:ws --limit=20` ثم `site:build`.
- أتمتة مجانية: GitHub Actions (‏2000 دقيقة/شهر، نحتاج ~30) يفتح Pull Request بالكتب الجديدة للمراجعة.
- التوسّع المرحلي: ويكي مصدر (كل اللغات) ← Standard Ebooks عبر GitHub ← LibriVox للصوتيات ← أرشيف الإنترنت بعد فلترة يدوية للعناصر.
