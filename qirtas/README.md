# منصة قِرطاس — موقع + تطبيق مكتبة الملكية العامة (عربي / إنجليزي)

موقع ثابت سريع + تطبيق ويب قابل للتثبيت (PWA) + مشروع أندرويد (Capacitor)، يقرآن من كتالوج واحد
وخط محتوى آلي يجذب الكتب من مصادر حرة قانونياً. **كل الأدوات مجانية** ولا يحتاج أي مفتاح API.

## التشغيل المحلي

```bash
cd qirtas
npm install            # مرة واحدة (cheerio لمعالجة النصوص)
npm run site:build     # توليد الموقع من الكتالوج
npm run site:serve     # معاينة على http://localhost:8081
```

## بنية المشروع

| المسار | الوظيفة |
|---|---|
| `books-data/catalog.json` | الكتالوج الرئيسي (مصدر الحقيقة) — ميتاداتا + مصدر + ترخيص |
| `books-data/index.json` | فهرس بحث خفيف للواجهة (يُبنى بـ `books:index`) |
| `books-data/texts/*.json` | نصوص الكتب مقسّمة فصولاً |
| `pipeline/` | خط المحتوى: جذب ← فلترة ← تنظيف ← إثراء ← فهرسة |
| `site/tools/build.js` | مولّد الموقع الثابت (صفحات كتاب، مكتبة بحث، إحصاءات، RSS، PWA) |
| `site/assets/` | CSS/JS الموقع (بلا اعتماديات أو أطر عمل) |
| `site/dist/` | الموقع الجاهز للنشر — **هذا ما يُرفع للاستضافة** |
| `docs/DEPLOYMENT.md` | دليل النشر الكامل + الحدود المجانية |
| `docs/PIPELINE.md` | المصادر والأساس القانوني وأوامر الجذب |
| `docs/ROLLBACK.md` | النسخ الاحتياطي والتراجع والمراقبة |

## أوامر خط المحتوى

```bash
npm run books:harvest                      # جوتنبرج: قائمة الأكثر تحميلاً (top-1000)
npm run books:fetch -- --limit=250         # تنزيل + تنظيف + تقسيم فصول
npm run books:ws    -- --limit=110         # ويكي مصدر العربية (اكتشاف آلي للكتب)
npm run books:ws-en -- --limit=40          # ويكي مصدر الإنجليزية
npm run books:openlibrary -- --lang=ar --limit=5000   # كتالوج خارجي (ميتاداتا + روابط)
npm run books:openlibrary -- --lang=en --limit=8000
npm run books:licenses                     # تدقيق ترخيص كتب ويكي مصدر
npm run books:license-labels -- --drop-review
npm run books:clean                        # إزالة التكرارات والنصوص اليتيمة
npm run books:clean-texts                  # إسقاط الفصول التنقلية والفارغة
npm run books:migrate                      # ترقية المخطط (مصدر/ترخيص/رابط/لغة)
npm run books:index                        # فهرس البحث للمكتبة
npm run site:build                         # إعادة توليد الموقع
npm run test:smoke                         # فحص HTTP شامل (52 فحصًا)
npm run test:ui                            # فحص تفاعلي بمتصفح حقيقي
```

## ما يعرضه الموقع

- `/` الرئيسية: أرقام حقيقية، أحدث الإضافات، التراث العربي، الكنوز الإنجليزية.
- `/library/` مكتبة كاملة: بحث عربي مطبَّع + فلاتر (لغة/تصنيف/مصدر) + ترتيب + ترقيم صفحات + مشاركة الرابط،
  وقسم **الكتالوج الخارجي** (Open Library/أرشيف الإنترنت) يُحمَّل عند الطلب بميتاداتا وروابط قراءة من المصدر.
- `/book/<id>/` صفحة كتاب SEO: وصف، فهرس حقيقي للفصول، **قسم المصدر والترخيص**، JSON-LD، canonical، OG.
- `/read/<id>/` القارئ: ترقيم أفقي RTL/LTR، وضع ليلي، حجم خط، فهرس، حفظ موضع القراءة، ورسائل خطأ واضحة.
- `/stats/` إحصاءات: توزيع الكتب حسب اللغة والمصدر والتصنيف + أطول الكتب.
- `/feed.xml`، `/sitemap.xml`، `/robots.txt`، `404`، `manifest.webmanifest` + Service Worker (قراءة دون إنترنت).

## التطبيق (PWA / أندرويد)

`reading-app-mvp/` تطبيق ويب قابل للتثبيت + مشروع أندرويد جاهز. لمزامنة الكتالوج الكامل معه:

```bash
cd ../reading-app-mvp
node tools/sync-catalog.js      # يبني js/books.js (ميتاداتا) وينسخ النصوص إلى books/
npm start                       # http://localhost:8080
```

النصوص تُحمَّل عند فتح الكتاب (lazy) وتُخزَّن للقراءة دون إنترنت عبر Service Worker.

## الحالات الحالية للكتالوج

- **المصادر**: Project Gutenberg (إنجليزي) + ويكي مصدر العربية/الإنجليزية.
- **الفحص**: تنظيف آلي للترويسات، تقسيم فصول، فلترة الحجم، ومراجعة عينات بشرية.
- **النمو**: أسبوعياً عبر GitHub Actions (`docs/DEPLOYMENT.md` §3).
