# قِرطاس (Qirtas) — MVP

تطبيق قراءة مجاني لكتب الملكية العامة — يعمل على كل المنصات من كود واحد (PWA)، ومعه **مشروع أندرويد أصلي جاهز للبناء** (Capacitor).

## التشغيل

```bash
npm install        # مرة واحدة (أدوات الموبايل فقط — التطبيق نفسه بلا اعتماديات)
npm start          # http://localhost:8080
```

## نسخة الموبايل (Android)

**جاهزة بالكامل**: مجلد `android/` مبني باسم «قِرطاس» وحزمة `app.qirtas.reader` وجميع الأيقونات وشاشات البداية. لبناء APK:

```bash
npm run build:mobile && cd android && .\gradlew.bat assembleDebug
```

الدليل الكامل (التوقيع، النشر على Play، استكشاف الأخطاء): [BUILD-MOBILE.md](BUILD-MOBILE.md)

## البنية

| الملف | الوظيفة |
|---|---|
| `index.html` + `css/` + `js/` | التطبيق (مكتبة + قارئ + PWA) |
| `js/books.js` | بيانات الكتب (نصوص ملكية عامة) |
| `sw.js` / `manifest.webmanifest` | العمل بلا إنترنت والتثبيت |
| `capacitor.config.json` + `android/` | مشروع أندرويد الأصلي |
| `tools/` | سكربتات التوليد (أيقونات، splash، mobile-dist) |
| `assets/` | أيقونة 1024 + splash 2732 المصدرية |
| `docs-screenshots/` | لقطات الشاشة المستخدمة في دراسة الحالة |
| `case-study.html` / `.pdf` | دراسة الحالة الكاملة |

## المميزات

- مكتبة كتب ملكية عامة (عربية + إنجليزية) مع بحث وتصنيفات وبطاقة «متابعة القراءة»
- قارئ بترقيم صفحات أفقي RTL/LTR، وضع ليلي/نهاري، تحكم بالخط، فهرس
- حفظ موضع القراءة تلقائياً + قراءة بلا إنترنت
- بنر تثبيت ذكي (Android prompt / تلميح iOS) ودعم safe-area للشاشات الحديثة
- إعلانات تجريبية (بانر + بيني) بمواضع AdMob المدروسة
